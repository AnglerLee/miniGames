# 잠수함 간식호 기획서

## 왜 만들었나

우리 집 탐정은 앉아서 생각하는 추리 게임이다. 같은 형식(부모가 준비하고, 아이가 혼자 하고, 부모는 관찰한다)으로 성격이 반대인 게임을 하나 더 만들었다. 이번에는 **몸을 쓰는 실시간 미션**이다.

| | 우리 집 탐정 | 잠수함 간식호 |
|---|---|---|
| 쓰는 것 | 머리 (모순 찾기) | 몸과 판단 (우선순위, 기억, 길 찾기) |
| 속도 | 천천히, 20~30분 | 빠르게, 15분쯤 |
| 준비 | 10분, 쪽지 7~11장을 숨긴다 | 5분, 쪽지 4~6장을 눈에 띄게 붙인다 |
| 다시 하기 | 쪽지를 새로 적어 붙인다 | 쪽지를 그대로 두고 바로 한다 |
| 부모가 보는 것 | 어디서 막히고 어떻게 추리하는지 | 급할 때 무엇을 먼저 하는지, 어떻게 외우는지 |

## 게임 한눈에

| | 내용 |
|---|---|
| 대상 | 10~12세 한 명 (폰 한 대) |
| 준비 | 부모 5분. 포스트잇과 펜, 보물상자 |
| 진행 | 아이 혼자 15분쯤 |
| 장소 | 집 안 방 4~6곳 |
| 끝 | 잠수함이 물 위로 올라오면 실제 보물의 위치나 자물쇠 번호가 공개된다 |

### 이야기

간식이 든 보물 상자가 바다 밑 1000미터에 가라앉았다. 우리 집이 잠수함 간식호다. 낡은 잠수함이라 내려가는 동안 방마다 고장이 난다. 승무원은 아이 하나뿐이다.

### 방이 구역이 된다

| 구역 | 그림 | 하는 일 |
|---|---|---|
| 조종실 | 🧭 | |
| 기관실 | ⚙️ | |
| 산소실 | 🫧 | |
| 부품 창고 | 📦 | 부품이 필요한 고장은 여기 먼저 들른다 |
| 통신실 | 📡 | 방이 5곳 이상일 때 |
| 수문 | 🚪 | 방이 6곳일 때 |

구역마다 쪽지를 붙인다. 쪽지에는 모양 하나와 숫자 네 개가 있다 (예 `▲ 4 8 1 6`).

### 아이가 하는 일

1. 경보가 뜬다. "기관실(부엌) 냉각 밸브가 잠겼다 0:42"
2. 그 방으로 걸어간다.
3. 폰에서 그 구역 버튼을 누르고, 쪽지를 보고 묻는 숫자를 누른다 ("셋째 숫자는?"). 그 방에 왔다는 확인이다. 질문은 매번 바뀐다.
4. 짧은 수리 놀이를 한다 (8~15초).
5. 시간 안에 못 고치면 선체가 깎인다. 선체가 0 이 되면 그 단계를 다시 한다.

### 단계

| 단계 | 수심 | 새로 나오는 것 |
|---|---|---|
| 출항 점검 | 0m | 시간 제한 없이 모든 구역을 한 번씩 돈다. 이때 아이의 걸음을 잰다 |
| 1. 잠항 | 300m | 고장이 하나씩 난다 |
| 2. 심해 | 800m | 두 곳이 한꺼번에 고장 난다. 부품 창고에서 부품을 챙겨 가야 하는 고장이 나온다 |
| 3. 보물 인양 | 1000m | 한 구역에서 본 기호 암호를 외워 다른 구역에 입력한다. 마지막에 크레인 순서대로 구역을 돈다 |
| 4. 긴급 부상 | 0m | 전부 섞여 나오고 시간이 조금 더 빡빡하다 |

### 수리 놀이 여섯 가지

| 놀이 | 하는 법 |
|---|---|
| 밸브 돌리기 | 손가락으로 원을 그려 바퀴를 돌린다 |
| 배관 잇기 | 조각을 눌러 돌려서 물길을 잇는다 |
| 압력 맞추기 | 흔들리는 바늘이 초록 칸에 올 때 누른다 |
| 물 새는 곳 막기 | 물이 새는 구멍을 눌러 막는다 |
| 펌프질 | 손잡이를 위아래로 끝까지 움직인다 |
| 재시동 암호 | 불이 켜진 순서를 따라 누른다 |

### 재미를 만드는 것

- **걸음에 맞춘 시간.** 출항 점검에서 잰 아이의 걸음이 제한 시간의 기준이 된다. 집이 넓든 좁든, 아이가 빠르든 느리든 비슷하게 아슬아슬하다. 뛸 필요가 없다.
- **무엇부터 고칠까.** 두 곳이 함께 고장 나면 급한 것은 선체 1칸, 느긋한 것은 2칸이 걸려 있다. 급한 것부터 하면 둘 다 해낼 수 있게 시간을 준다.
- **들르는 순서.** 부품이 필요한 고장은 창고를 거쳐야 한다. 길을 머릿속으로 짜야 한다.
- **걸으면서 외우기.** 기호 암호를 보고 다른 방까지 가는 동안 잊지 않아야 한다. 잊으면 돌아가서 다시 볼 수 있지만 시간이 든다.
- **다시 도전하면 넉넉해진다.** 가라앉으면 그 단계만 다시 하고, 제한 시간이 18%씩 는다.
- **잃을 것이 있다.** 간식은 반드시 얻는다. 부모가 정한 보너스 보상은 등급 기준을 넘어야 공개된다.

### 부모가 하는 일

| 때 | 하는 일 |
|---|---|
| 준비 | 방을 고르고, 보물 정보를 적고, 구역 쪽지를 붙이고, 바닥을 치운다 |
| 시작 직전 | 관찰자 예측 세 가지 (선체 손상, 다시 도전 여부, 가장 힘들어할 단계) |
| 게임 중 | 지켜본다. 비상시에만 부모 메뉴(확인 번호)로 단계를 넘기거나 끝낸다 |
| 끝난 뒤 | 관찰 리포트: 단계별 기록, 급할 때의 판단, 기억, 여유, 걸음의 변화, 예측과 실제, 아이에게 해 줄 칭찬 문장 |

### 안전

아이가 폰을 들고 방 사이를 오간다. 준비 화면이 바닥 정리, 미끄러운 양말, 문턱을 확인하게 한다. 게임은 뛰지 말고 걸으라고 알려 주고, 시간도 걸음에 맞춰 준다.

### 난이도 (시작값)

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 걸음 여유 배수 | 2.4 | 1.9 | 1.55 |
| 선체 | 6칸 | 5칸 | 4칸 |
| 경보 묶음 (잠항/심해/인양/부상) | 3/3/2/3 | 3/4/2/4 | 4/5/3/5 |
| 두 곳 동시 고장 | 2번 | 4번 | 8번 |
| 도착 확인 | 몇째 숫자 | + 가장 큰·작은 숫자 | + 두 숫자 차례로 |
| 외울 기호 | 3개 | 4개 | 5개 |
| 크레인 순서 | 3곳 | 4곳 | 5곳 |

수치는 `js/shared/content.js` 의 `DIFFICULTY` 와 `js/shared/score.js` 의 `RULES` 에 있다. 실제로 해 본 뒤 고친다.

## 규칙을 다루는 방법

- **규칙 엔진** (`js/shared/engine.js`): 화면 없이 상태만 바꾸는 순수 함수다. 화면은 엔진에 사건(시간 흐름, 도착, 수리 완료)을 보내고 결과를 그린다.
- **임무 생성** (`js/shared/plan.js`): 씨앗과 잰 걸음으로 단계별 경보를 만든다. 제한 시간은 `걸음 수 × 걸음 × 여유 배수 + 도착 확인 + 수리 시간 + 반응 시간` 이다. 두 경보가 함께 뜨면 두 번째에 첫 번째의 시간을 더한다.
- **검증** (`tests/engine.test.js`): 가상의 아이가 난이도 3단계 × 방 4~6곳에서 끝까지 한다. 잰 걸음 그대로 걷는 아이는 모든 임무를 해낼 수 있다는 것을 씨앗 250개 × 걸음 3가지로 확인한다.

## 파일 구조

```
home-submarine/
  index.html      대문 (준비, 임무 시작, 지난 기록)
  setup.html      부모 준비 마법사
  play.html       아이 임무 화면
  lab.html        수리 놀이 시험대 (개발용)
  lab-ending.html 결말 화면 시험대 (개발용)
  css/            base.css(공용) setup.css play.css ending.css
  js/shared/      구역 쪽지, 임무 생성, 규칙 엔진, 점수, 저장, 문장
  js/setup/       준비 마법사
  js/play/        임무 화면, 결말, 관찰 리포트, 소리
  js/play/tasks/  수리 놀이 6종
  tests/          node --test "tests/*.test.js"
  docs/           이 문서, 실행 안내
```

저장은 모두 이 기기 안의 localStorage(`minigames:homeSubmarine_*`)에 한다. AnglerBox 에서 여러 앱이 한 주소를 함께 쓰므로 키 앞에 `minigames:` 를 붙인다. 다른 기기로는 준비 내용을 담은 링크(`play.html#c=…`)로 넘긴다. 서버로 보내는 것은 없다.
