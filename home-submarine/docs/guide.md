# 잠수함 간식호 실행과 진행 안내

## 실행

ES 모듈을 쓰므로 파일을 더블클릭해서는 열리지 않는다. 아래 둘 중 하나로 연다.

**집 Wi-Fi 에서 (PC 를 서버로)**

```bash
python3 operation-vault/serve.py        # 저장소 루트를 8000번 포트로 연다
```

폰 브라우저에서 `http://<PC 주소>:8000/home-submarine/` 를 연다.

**GitHub Pages**

저장소의 Pages 주소 뒤에 `/home-submarine/` 를 붙인다.

## 준비물

포스트잇(방 수만큼, 4~6장)과 펜, 보물상자와 간식.

## 부모 준비 (5분)

아이가 쓸 폰에서 준비한다.

1. 대문에서 "잠수함 준비하기"를 누른다.
2. 아이 이름과 난이도를 정한다.
3. 방을 4~6곳 고른다. 방마다 구역이 정해진다. 바꾸고 싶으면 두 줄을 눌러 맞바꾼다.
4. 보물 정보와 보너스 보상을 적는다.
5. 화면이 보여 주는 대로 포스트잇에 모양과 숫자 네 개를 적어, 각 방의 눈에 잘 띄는 곳에 붙인다.
6. 보물상자를 숨기고 바닥을 치운다.
7. 관찰자 예측 세 가지를 고르고 "아이에게 폰 건네기"를 누른다.

## 게임 중 (부모는 관찰)

- 끼어들지 않는다. 고장을 놓쳐도 게임이 다시 기회를 준다.
- 전화가 오는 등 잠깐 멈춰야 하면 멈춤 버튼을 쓴다. 화면이 가려지면 게임이 알아서 멈춘다.
- 비상시에만 메뉴 > 부모 메뉴에서 확인 번호를 넣고 단계를 넘기거나 임무를 끝낸다.

## 끝난 뒤

아이가 보물을 찾으면 폰을 돌려받아 "관찰 리포트 보기"를 누른다.

## 다시 할 때

쪽지를 떼지 않았으면 대문의 "쪽지 그대로 새 임무"를 누른다. 준비 없이 바로 시작한다. 고장 나는 곳과 순서는 매번 달라진다.

## 검증

```bash
cd home-submarine && node --test "tests/*.test.js"
```

화면은 `?debug=1` 을 붙여 열면 `window.__hs` (임무 화면), `window.__hsSetup` (준비 화면) 손잡이가 열린다. 수리 놀이 하나만 보려면 `lab.html?task=valve&seed=3&level=1` 을 연다.

## 실제 폰에서 확인할 것

PC 의 자동 검증으로는 알 수 없는 것들이다.

- 제한 시간이 우리 집과 아이의 걸음에 맞는지 (가장 중요하다. `DIFFICULTY` 의 `factor` 로 고친다)
- 걸으면서 화면이 한눈에 읽히는지
- 수리 놀이의 손맛과 걸리는 시간
- 소리 크기와 진동
- 화면 꺼짐 방지 (지원하지 않는 기기에서는 화면이 꺼지면 게임이 멈춘다)
