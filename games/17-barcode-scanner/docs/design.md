# 바코드 몬스터 기획

## 핵심 재미

집 안 물건의 바코드를 찍으면 그 번호에서 몬스터가 태어납니다. 카드가 흔들리다 뒤집히는 순간이 뽑기의 설렘이고, "불 속성이 필요한데 뭐가 나올까?" 하며 집 안을 뒤지는 것이 탐험입니다. 같은 번호는 언제나 같은 몬스터라서 "우리 집 우유는 활활방구룡"처럼 기억에 남고, 도감에 쌓입니다.

## 바코드 → 몬스터

번호의 해시(cyrb53 → mulberry32)로 정합니다. 순수 함수라 Node 에서 같은 번호 → 같은 몬스터, 속성 분포를 시험합니다(`game.js` 맨 앞).

| 항목 | 정하는 법 |
|---|---|
| 속성 | 🔥불 💧물 🌿풀 ⚡번개 ⛰️땅. 각 20% |
| 희귀도 | 끝 두 자리가 같으면 ★★★ 전설(약 10%). 나머지는 해시로 ★★(약 23%) 또는 ★ |
| 힘 | ★ 10~49, ★★ 40~74, ★★★ 70~99 |
| 모양 | 속성별 몸통 이모지 8개 + 장식 16개 |
| 이름 | 속성 말머리 + 웃긴 두 글자 + 끝말 (예: 활활방구룡, 첨벙콧물냥) |
| 황금 몬스터 | 관리자가 등록한 바코드. 힘 999, 👑 |

12자리 UPC-A 는 앞에 0 을 붙인 EAN-13 과 같은 바코드로 봅니다(읽는 도구마다 결과가 달라도 같은 몬스터).

상성은 고리 하나입니다: 불 › 풀 › 땅 › 번개 › 물 › 불. 보스를 이기는 속성은 힘 1.5배.

## 진행

한 판은 사냥 임무 3개입니다. 스테이지마다 시간 막대가 따로 있고, 카드가 뒤집히는 동안은 시간이 멈춥니다.

| 스테이지 | 임무 | 새 규칙 |
|---|---|---|
| 1 사냥 | 서로 다른 바코드 N개 | 아무 몬스터나. 뽑기와 카드 공개를 익힌다 |
| 2 속성 사냥 | 정해진 두 속성(예: 🔥불·⛰️땅) 몬스터 M마리 | 다른 속성은 팀에만 들어가고 임무는 그대로. 더 찾아야 한다 |
| 3 보스전 | 팀에서 3마리를 골라 힘의 합이 보스보다 크면 승리 | 상성 1.5배를 따져 고른다. 모자라면 더 잡아 온다 |

- 2단계 목표 속성 하나는 늘 보스를 이기는 속성입니다(판을 시작할 때 보스 속성을 먼저 정한다).
- 보스 힘 = min(설정값 ± 6 − 재도전 × 12, 지금 팀 최강 + 45). 보스전 화면에 "끝 두 자리가 같은 바코드는 ★★★"를 알려 줍니다. 시뮬레이션(2만 판)에서 이 팁대로 번호를 보고 골라 찍으면 **늘 2마리 안에** 이깁니다. 아무거나 찍으면 운이 나쁠 때 오래 걸리므로, 번호를 읽고 고르는 것이 실력이 됩니다.
- 보스 화면에는 상성 고리를 보여 주고, 보스를 이기는 몬스터 카드에는 `37→56`처럼 바뀐 힘을 적습니다.

### 황금 몬스터 (부모가 바코드를 등록했을 때)

등록한 바코드를 찍으면 황금 몬스터(힘 999, 더 긴 두근두근, 꽃가루)가 나옵니다. 3단계가 **황금 사냥**으로 바뀝니다: 보스 힘이 450 + 999 × (찾을 수 − 1) 이상이라 황금 몬스터를 팀에 넣어야만 이깁니다. 시간은 1.5배, 관리자가 적은 힌트가 보입니다. 숨긴 물건을 찾게 하는 보물찾기 단서로 쓰기 좋습니다. 앞 스테이지에서 미리 찾으면 그대로 팀에 남습니다.

## 잡는 방법 (카메라가 없어도 끝까지)

| 방법 | 내용 |
|---|---|
| 카메라 | `BarcodeDetector` 가 있으면 그것, 없으면 CDN 의 quagga2 를 뒤에서 불러온다(시작을 막지 않는다). quagga2 는 장면마다 세 가지 방법(네모만 훑기, 화면 전체에서 찾기, 큰 조각으로 찾기)을 돌아가며 쓰고, 같은 번호가 2.5초 안에 두 번 읽혀야 믿는다 |
| 번호 입력 | 큰 키패드로 8·12·13자리. 끝자리(확인 숫자)가 틀리면 안 잡히고 **시간 −4초**. 아무 숫자나 눌러 잡는 것을 막는다(무작위 번호는 10%만 통과) |
| 사진 | `capture=environment` 파일 올리기. 사진 앱에 다녀온 시간만큼 시간 막대에서 뺀다 |

https 나 localhost 가 아니면 카메라가 막히므로 번호 입력이 기본이 되고 이유를 보여 줍니다. 카메라 권한 거부, 카메라 없음, quagga2 를 못 불러옴(15초 기다림)도 번호 입력으로 넘어갑니다.

## 긴장과 보상

- 스테이지마다 줄어드는 시간 막대. 다 줄면 실패.
- 같은 바코드를 다시 찍으면 "이미 잡았어!". 카메라는 같은 바코드를 계속 읽으므로 안내는 3초에 한 번.
- 연속 포획: 앞 몬스터를 잡고 20초 안에 다음을 잡으면 점수 ×1.2, ×1.4 … (최대 ×1.8). 위쪽 임무 칸 아래 막대가 남은 시간을 보여 주고, 카드 공개 문구에 몇 연속인지 나온다. 엔진의 콤보 표시는 임무 칸을 가려서 쓰지 않는다.
- 귀할수록 카드 뒷면이 오래 흔들리고(★★★ 은 무지개 테두리, 황금은 금빛), 뒤집힌 뒤 소리·조각·번쩍임이 커진다.
- 점수: 잡을 때 힘 × 10(황금 3000) × 연속 배율, 2단계 목표 속성 ×1.5, ★★★ +300, 도감에 처음 +100. 스테이지를 넘기면 남은 초 × 10, 보스를 이기면 1000 + 여유 힘 × 10.
- "안전하게 갈까, 욕심낼까": 이길 수 있게 되면 바로 공격할 수도 있고, 더 센 몬스터를 잡아 와 여유를 키워 별을 노릴 수도 있다(그동안 시간은 흐른다).

## 도감

`barcodeMonsterDex` 에 번호만 쌓습니다(최대 500개, 판이 끝나도 남는다). 몬스터는 번호에서 다시 만듭니다. 시작 화면에 도감 수, 플레이 중 📖 단추로 도감 보기, 결과 화면에 "새로 도감에 N마리"와 이번에 잡은 몬스터 줄이 나옵니다. 판마다 "이미 잡았어"는 그 판 안에서만 따지므로, 집에 바코드가 많지 않아도 다시 할 수 있습니다.

## 별 기준

| 별 | 조건 |
|---|---|
| +1 | 클리어 |
| +1 | 스테이지를 넘길 때 남은 시간 비율의 평균이 35% 이상 |
| +1 | 보스전 여유: 팀 힘이 보스보다 15% 이상 큼 |

재도전으로 깬 판은 최대 2개입니다.

## 실패와 재도전

시간이 다 되면 그 스테이지부터 다시 합니다. 그 스테이지가 시작될 때의 팀(앞 스테이지에서 잡은 몬스터)과 판의 계획(2단계 속성, 보스 속성)은 그대로 이어지고, 그 스테이지에서 잡은 것만 비웁니다. 재도전마다 스테이지 시간 +15초, 보스 힘 −12 (최대 3번).

## 설정 (`barcodeScannerSettings`)

| 키 | 쉬움 | 보통 | 어려움 | 뜻 |
|---|---|---|---|---|
| `timeLimit` | 100 | 85 | 75 | 1단계 시간(초). 2단계 1.3배, 보스전 1배, 황금 사냥 1.5배. 40~300 |
| `targetCount` | 3 | 3 | 4 | 1단계에서 잡을 수. 2~6 |
| `elemNeed` | 2 | 2 | 3 | 2단계 목표 속성 몬스터 수. 1~4 |
| `bossPower` | 165 | 185 | 210 | 보스 힘. 80~300 |
| `goldCount` | 1 | 1 | 1 | 찾아야 할 황금 몬스터 수(`'1'`~`'3'`, 등록 수보다 많으면 등록 수) |
| `goldHint` | '' | '' | '' | 황금 사냥 때 보여 줄 힌트 |
| `targetBarcodes` | | | | 부모가 등록한 바코드(황금 몬스터). 관리자 페이지에서 추가·삭제하는 즉시 저장되고 "초기화"해도 남는다 |

옛 관리자 페이지가 저장한 값도 그대로 씁니다. 범위를 벗어난 값(예: 옛 `timeLimit: 0` = 무제한, `targetCount: 1`)은 난이도 기본값으로 바꿉니다. 게임과 관리자 페이지가 같은 규칙을 씁니다.

관리자 페이지는 `game.js` 를 불러 바코드 읽기 도구와 몬스터 미리보기를 같이 씁니다(엔진이 없으면 게임은 만들지 않는다). 바코드는 번호 입력(확인 숫자 검사), 카메라 스캔, 사진에서 읽기로 등록하고, 삭제는 두 번 눌러야 됩니다.
