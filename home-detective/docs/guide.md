# 우리 집 탐정 실행과 진행 안내

## 실행

ES 모듈을 쓰므로 파일을 더블클릭해서는 열리지 않는다. 아래 둘 중 하나로 연다.

**집 Wi-Fi 에서 (PC 를 서버로)**

```bash
python3 operation-vault/serve.py        # 저장소 루트를 8000번 포트로 연다
```

폰 브라우저에서 `http://<PC 주소>:8000/home-detective/` 를 연다. 사진 찍기는 파일 선택 방식이라 `http` 주소에서도 된다.

**GitHub Pages**

저장소의 Pages 주소 뒤에 `/home-detective/` 를 붙인다.

|---|---|---|---|
| 쉬움 | 7장 | 4개 | 펜, 보물상자와 간식 |

인형이 모자라면 로봇, 자동차, 그림을 써도 된다. 프린터가 있으면 준비 화면의 "쪽지 인쇄하기"로 쪽지를 뽑을 수 있다.

## 부모 준비 (10분)

아이가 쓸 폰에서 준비한다. 사진이 그 폰에만 남기 때문이다.

1. 대문에서 "새 사건 준비하기"를 누른다.
2. 아이 이름, 난이도, 제한 시간을 정한다.
3. 집에 있는 방을 4~6곳 고른다.
4. 인형의 이름을 적는다. 사진을 찍어 두면 게임에 그 인형이 나온다.
5. 보물 정보(자물쇠 번호나 숨긴 곳)와 보너스 보상을 적는다.
6. 화면이 알려 주는 대로 포스트잇에 기호를 적어 붙인다.
   - 인형 쪽지: 인형에 붙이고 안내한 방에 둔다.
   - 증거 쪽지: 안내한 방 어딘가에 숨긴다.
   - 쪽지마다 숨긴 곳 힌트를 글이나 사진으로 남긴다. 아이가 막혔을 때 게임이 대신 알려 준다.
7. 보물상자를 숨긴다.
8. 관찰자 예측 세 가지를 고르고 "아이에게 폰 건네기"를 누른다.

부모 폰에서 준비하고 아이 폰으로 하려면 마지막 단계의 "다른 폰으로 하기" 주소를 보낸다. 이때 사진은 넘어가지 않고 힌트 글만 넘어간다.

## 게임 중 (부모는 관찰)

- 끼어들지 않는다. 막히면 아이가 무전 버튼으로 힌트를 받는다.
- 쪽지가 떨어져 없어졌을 때만 메뉴 > 부모 메뉴에서 확인 번호를 넣고 "찾은 것으로 처리"를 누른다.
- 전화가 오는 등 잠깐 멈춰야 하면 메뉴 > 잠깐 멈춤을 쓴다.

## 끝난 뒤

아이가 보물을 찾으면 폰을 돌려받아 "관찰 리포트 보기"를 누른다.

## 다시 할 때

준비 화면 첫 장의 "지난번 방과 인형 그대로 새 사건 만들기"를 누르면 방, 인형, 사진은 그대로 두고 범인과 쪽지 기호만 바뀐다. 쪽지는 새로 적어 붙여야 한다.

## 검증

```bash
cd home-detective && node --test "tests/*.test.js"
```

화면은 `?debug=1` 을 붙여 열면 `window.__hd` (수사 화면), `window.__hdSetup` (준비 화면) 손잡이가 열린다. 증거 장면 하나만 보려면 `lab.html?scene=dust&seed=3&d=1` 을 연다.

## 실제 폰에서 확인할 것

PC 의 자동 검증으로는 알 수 없는 것들이다.

- 문지르기, 돌리기, 조각 옮기기의 손맛과 감도
- 소리 크기와 진동
- 카메라로 사진 찍기와 저장 공간
- 화면 꺼짐 방지 (지원하지 않는 기기에서는 화면이 꺼질 수 있다. 시계는 꺼져 있는 동안에도 흐른다)
- 제한 시간과 벌점 수치가 아이에게 맞는지
