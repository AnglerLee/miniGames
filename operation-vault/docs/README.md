# 작전명 스낵 볼트

폰 두 대로 하는 협력 금고 침투 게임입니다. 아이는 현장 요원이 되어 3D 보안 시설을 뚫고, 부모는 본부 오퍼레이터가 되어 보안 매뉴얼을 보며 말로 도와줍니다. 금고를 열면 실제 보물상자(간식)를 여는 방법이 공개됩니다.

- 권장 연령: 10~12세 (부모와 함께)
- 한 판 길이: 12~18분
- 필요한 것: 같은 Wi-Fi에 연결된 폰 두 대, 이 저장소를 실행할 컴퓨터 한 대, 간식을 넣은 보물상자

## 실행 방법

컴퓨터에서 서버를 켭니다.

```bash
cd operation-vault
python3 serve.py
```

화면에 나오는 "부모 폰에서 열 주소"(예: `http://192.168.0.10:8000/operation-vault/`)를 부모 폰 브라우저에 입력합니다.

파일을 더블클릭해서 여는 방식으로는 실행되지 않습니다. 반드시 위 서버로 여세요.

## 한 판 진행 순서

### 부모 (본부 오퍼레이터)

1. 시작 화면에서 **본부 오퍼레이터**를 누릅니다.
2. 작전 설정을 채웁니다.
   - 난이도와 제한 시간
   - 보물 공개 방식: 자물쇠 번호, 숨긴 장소, 열쇠 위치, 자유 문구 중 하나와 그 내용
   - 보너스 보상 (선택): 한 번도 발각되지 않고 A등급 이상이어야 공개됩니다
   - 보안 토큰 (선택): 집 안에 숨긴 쪽지를 아이가 실제로 찾아와야 하는 단계입니다
3. **작전 만들기**를 누르면 QR과 작전 코드 12자리가 나옵니다.
4. 간식을 보물상자에 넣어 둡니다. 보안 토큰을 켰다면 화면에 나온 번호를 쪽지에 적어 숨깁니다.

### 아이 (현장 요원)

1. 아이 폰 카메라로 QR을 찍습니다. 안 되면 같은 주소에서 **현장 요원**을 누르고 작전 코드를 입력합니다.
2. **작전 개시**를 누르면 화면에 주파수 네 자리가 나옵니다.

### 함께

1. 아이가 주파수를 불러 주면 부모가 **매뉴얼** 탭에 입력합니다. 그 단계의 매뉴얼이 열립니다.
2. 매뉴얼 맨 위의 대사를 부모가 소리 내어 읽고, 아이는 화면에 보이는 것을 말로 설명합니다.
3. 단계가 바뀔 때마다 주파수가 바뀝니다. 그때마다 **주파수 바꾸기**를 눌러 새 숫자를 입력합니다.
4. 금고가 열리면 아이 화면에 개봉 코드 네 자리가 나옵니다. 부모가 **개봉** 탭에 입력하면 보물 정보가 공개됩니다.

## 단계

| 단계 | 아이 화면 | 부모 매뉴얼 |
|---|---|---|
| 교신 점검 | 암구호 보기 네 개 | 암구호 한 단어 |
| 정문 게이트 | 이름 없는 문양 네 개와 키패드 | 문양 사전, 색 보정표 |
| 환기 덕트 | 1인칭 덕트 미로 | 설계도 (벽, 표식, 감지선, 출구) |
| 전력실 | 스위치 6개와 장치 상태등 | 배전표 |
| 보안 토큰 (선택) | 번호 입력 단말기 | 쪽지 힌트 |
| 금고실 | 금고 다이얼 | 명판별 변환표 |

## 규칙

- 제한 시간이 실제로 줄어듭니다. 0이 되면 발각됩니다.
- 실수하면 경보가 1단계 오르고 30초가 깎이며, 장치 상태가 다시 섞입니다. 매뉴얼은 그대로입니다.
- 단계를 통과하면 경보가 1단계 내려갑니다.
- 경보가 5단계가 되면 발각됩니다.
- 발각되면 같은 단계를 새 주파수로 다시 시작합니다. 매뉴얼 내용이 바뀌고, 남은 시간은 최소 2분 30초가 보장됩니다.
- 간식은 잃지 않습니다. 보너스 보상만 사라집니다.
- 너무 오래 막히면 부모가 **지원** 탭에서 우회 코드를 발급해 그 단계를 건너뛰게 할 수 있습니다. 아이는 ☰ 메뉴의 "본부 지원 코드"에 입력합니다.

등급 기준은 다음과 같습니다.

| 등급 | 조건 |
|---|---|
| S | 발각과 우회 없이, 실수 1회 이하, 시간 30% 이상 남김 |
| A | 발각과 우회 없음 |
| B | 발각 1회 이하 (우회 사용 포함) |
| C | 발각 2회 이상 |

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 아이 폰에서 주소가 열리지 않음 | 두 폰과 컴퓨터가 같은 Wi-Fi인지 확인합니다. 주소가 `localhost`로 시작하면 다른 기기에서 열리지 않습니다 |
| 주파수가 맞지 않는다고 나옴 | 숫자를 다시 확인합니다. 계속 안 되면 두 폰 모두 새로고침합니다. 진행은 저장되어 있습니다 |
| 아이 폰을 실수로 닫음 | 같은 주소를 다시 열고 "이어하기"를 누릅니다. 하던 단계의 처음부터 이어집니다 |
| 소리가 안 남 | 브리핑 화면의 "소리 시험"을 눌러 봅니다. 아이폰은 무음 스위치도 확인합니다 |
| 아이 폰이 꺼지거나 고장 남 | 부모 폰의 개봉 탭에서 "코드 없이 공개하기"를 씁니다 |
| 화면이 자꾸 꺼짐 | 폰 설정에서 화면 자동 꺼짐 시간을 2분 이상으로 늘립니다 |

끝낸 작전의 등급과 기록은 아이 폰에 저장되며, 아이 폰에서 시작 화면을 열면 "이 폰의 지난 작전"에 나옵니다.

진동과 전체 화면은 기기에 따라 동작하지 않을 수 있습니다. 그런 기기에서는 소리와 화면 효과만 나옵니다.

## 수치 조정

실제로 해 보고 조정할 값은 아래 파일에 모여 있습니다.

| 조정할 것 | 파일 |
|---|---|
| 실수 벌점, 발각 기준, 등급 기준 | `js/shared/run.js`의 `rulesFor`, `rankOf` |
| 난이도별 제한 시간 | `js/shared/mission.js`의 `DIFFICULTIES`, `TIME_PRESETS_MIN` |
| 문양 수, 색 수, 문양 유효 시간 | `js/shared/puzzles/glyphgate.js`의 `CONFIG` |
| 미로 크기, 감지선 수, 스프레이 횟수 | `js/shared/puzzles/ductmaze.js`의 `CONFIG` |
| 과부하 제한, 최소 조작 횟수 | `js/shared/puzzles/powergrid.js`의 `CONFIG` |
| 명판 수, 계산 난도 | `js/shared/puzzles/vaultdial.js`의 `CONFIG` |
| 다이얼의 "천천히" 기준과 확정 시간 | `js/agent/stages/vault.js`의 `SLOW_MS`, `HOLD_FILL_MS` |

퍼즐 내용은 씨앗에서 만들어지므로, 위 값을 바꾸면 이미 만들어 둔 작전 코드의 내용도 달라집니다. 진행 중인 판이 없을 때 바꾸세요.

## 구조

```
index.html       시작 화면
setup.html       작전 설정 (부모)
operator.html    본부 콘솔 (부모): 작전 코드, 매뉴얼, 지원, 개봉
agent.html       현장 요원 (아이): 3D 게임
serve.py         실행용 서버
js/shared/       두 폰이 함께 쓰는 로직. 퍼즐 내용이 여기서 만들어진다
js/agent/        아이 화면: 3D 엔진, 단계 장면, HUD, 소리
js/operator/     부모 화면: 탭과 매뉴얼
js/setup/        설정 화면
vendor/          three.js 0.187.0, qrcode-generator 2.0.4
tests/           공용 로직 테스트
```

두 폰은 서로 통신하지 않습니다. 작전 코드에 들어 있는 씨앗으로 양쪽이 같은 퍼즐을 만들어 내고, 사람이 말로 주고받는 숫자(주파수, 개봉 코드, 우회 코드)로 상태를 맞춥니다. 보물 정보와 쪽지 힌트는 부모 폰에만 저장됩니다.

## 테스트

```bash
cd operation-vault
npm test
```

많은 씨앗에 대해 "매뉴얼과 아이가 볼 수 있는 것만으로 반드시 풀리는가"를 확인합니다. 씨앗 수는 `SEEDS=2000 npm test`처럼 바꿀 수 있습니다.

아이 화면 주소 뒤에 `?debug=1`을 붙이면 브라우저 콘솔에서 `__opVault.autoSolve()`, `__opVault.setTimeScale(20)` 같은 검증용 기능을 쓸 수 있습니다.
