# 🎮 보물찾기 미니게임 모음

집에서 아이들과 함께 즐기는 보물찾기 게임을 위한 웹 기반 미니게임 모음입니다!

![보물찾기 미니게임](docs/thumbnail.png)

## 🌐 바로가기

- 게임 목록 (아이): https://pros2.synology.me/minigames/
- 부모 대시보드: https://pros2.synology.me/minigames/admin.html
- 게임 설명서 (화면과 함께 보는 준비·진행 안내): https://pros2.synology.me/minigames/guide/

이렇게 씁니다.

1. 부모가 대시보드에서 보물찾기를 골라 **준비하기**를 누릅니다. 준비 내용은 부모 기기에 저장됩니다.
2. 준비가 끝나면 **아이에게 보내기**를 누르고, QR을 보여 주거나 링크를 메신저로 보냅니다.
3. 아이는 링크를 연 기기에서 혼자 시작합니다. 진행과 기록, 관찰 리포트는 그 기기에 남습니다.

NAS(AnglerBox)에 게시하는 방법은 [docs/deploy-anglerbox.md](docs/deploy-anglerbox.md)에 있습니다.

## ✨ 특징

- 📱 **모바일 친화적**: 스마트폰에서 터치로 쉽게 플레이
- 🎯 **20가지 미니게임**: 게임마다 스테이지 3개, 하트·시간·콤보, 별 1~3개 등급
- ⭐ **별 모으기**: 게임 목록에서 전체 별, 칭호, 날마다 바뀌는 "오늘의 도전" 3개
- 🏠 **홈 트레저헌트**: 디지털 + 실물 보물찾기 하이브리드 시스템
- 🎨 **9가지 테마**: 미스터리, 해적, 우주, 마법, 공룡, 정글, 바다, 닌자, 유령의집
- 👥 **1~2인 모드**: 혼자 또는 둘이서 번갈아 플레이
- 🔐 **관리자 PIN**: 4자리 PIN으로 설정 보호
- 💾 **서버 불필요**: 모든 데이터는 브라우저 localStorage에 저장
- 📨 **아이에게 링크 보내기**: 부모 대시보드에서 보물찾기 준비 내용을 링크·QR로 아이 기기에 보낸다
- 🎊 **풍부한 효과**: 효과음과 배경 리듬, 화면 연출, 진동(되는 기기만)
- 🕶️ **작전명 스낵 볼트**: 폰 두 대로 하는 3D 협력 금고 침투 게임 (`operation-vault/`)
- 🕵️ **우리 집 탐정**: 부모가 준비하고 아이가 혼자 푸는 추리 게임. 인형이 용의자, 집이 사건 현장 (`home-detective/`)
- 🚢 **잠수함 간식호**: 부모가 준비하고 아이가 혼자 하는 실시간 미션. 집이 잠수함, 방마다 터지는 고장을 걸어 다니며 고친다 (`home-submarine/`)

## 🏠 홈 트레저헌트 (treasure-hunt3)

디지털 미니게임과 실물 보물찾기를 결합한 하이브리드 보물찾기 시스템입니다.

### 핵심 컨셉

1. 아이가 **미니게임 미션**을 클리어하면 **단서(힌트)** 를 획득
2. 단서를 조합하여 **집 안 어딘가에 숨겨진 보물**의 위치를 추리
3. 보물을 찾으면 **비밀번호**를 입력하여 보물상자를 오픈!

### 아키텍처

```
index.html ──── #main (시작 화면)
    │           #intro (스토리 인트로)
    │           #hub  (미션 허브)
    │
    ├── play.html?type=mini&idx=0  ── 미니게임 (iframe)
    ├── play.html?type=find&idx=1  ── 물건찾기 미션
    │
    └── treasure.html ─────────────── 보물상자 (비밀번호 입력)

admin.html ──── PIN 인증 → 대시보드 (설정 관리)
```

### 페이지별 기능

| 페이지 | 역할 | 주요 기능 |
|--------|------|-----------|
| `index.html` | 메인 & 허브 | 시작 화면, 스토리 인트로, 미션 목록, 진행률, 단서 모음 |
| `admin.html` | 관리자 설정 | PIN 인증, 테마/시나리오 선택, 미션 구성, 옵션 설정 |
| `play.html` | 미션 플레이 | 미니게임 iframe 로드, 물건찾기(힌트+정답), 클리어 오버레이 |
| `treasure.html` | 보물상자 | 3D 보물상자 애니메이션, 비밀번호 입력, 결과 & 성적 표시 |

### 9가지 테마

| 테마 | ID | 색상 톤 |
|------|----|---------|
| 🔍 미스터리 탐정 | `mystery` | 다크 블루 + 골드 |
| 🏴‍☠️ 해적 보물 | `pirate` | 브라운 + 골드 |
| 🚀 우주 탐험 | `space` | 딥 블루 + 시안 |
| 🧙 마법 학교 | `magic` | 퍼플 + 핑크 |
| 🦕 공룡 발굴 | `dino` | 그린 + 오렌지 |
| 🌴 정글 탐험 | `jungle` | 다크 그린 + 라임 |
| 🐠 심해 탐험 | `ocean` | 네이비 + 시안 |
| 🥷 닌자 수련 | `ninja` | 다크 그레이 + 레드 |
| 👻 유령의 집 | `haunted` | 퍼플 + 퍼플 |

각 테마에는 2개 이상의 프리셋 시나리오가 포함되어 있어 바로 플레이할 수 있습니다.

### 미션 타입

**🎮 미니게임 미션 (`minigame`)**
- 20개 미니게임 중 선택하여 iframe으로 로드
- postMessage 통신으로 클리어 감지
- 2인 모드 시 플레이어가 번갈아 플레이

**🔎 물건찾기 미션 (`findObject`)**
- 집 안에서 실물을 찾는 미션
- 최대 3개 힌트 (단계적 공개, 3회 실패 시 전체 공개)
- 정답 입력 (대소문자/공백 무시)
- 2인 모드 시 함께 협력 플레이

### 관리자 옵션

| 옵션 | 설명 |
|------|------|
| 테마 선택 | 9개 테마 중 선택 |
| 시나리오 선택 | 테마별 프리셋 시나리오 로드 |
| 미션 구성 | 미니게임/물건찾기 추가, 순서 변경, 삭제 |
| 플레이어 수 | 1인 / 2인 모드 (이름 설정) |
| 시간 제한 | 전체 게임 시간 제한 (분 단위, OFF 가능) |
| 보물 비밀번호 | 최종 보물상자 오픈 비밀번호 |
| 비밀 코드 | 보물상자 오픈 후 표시되는 코드 |
| 단서 표시 | 허브 화면에서 수집한 단서 표시/숨김 토글 |
| 관리자 PIN | 4자리 PIN 변경 (기본: 0000) |

### localStorage 키

AnglerBox 에서는 여러 앱이 한 주소를 함께 쓰므로 이 사이트의 모든 키 앞에 `minigames:` 를 붙입니다.

| 키 | 용도 |
|----|------|
| `minigames:treasureHunt3_config` | 게임 설정 (테마, 미션, 옵션 등) |
| `minigames:treasureHunt3_state` | 게임 진행 상태 (현재 미션, 결과, 단서) |
| `minigames:treasureHunt3_admin` | 관리자 PIN |
| `minigames:treasureHunt3_history` | 플레이 기록 (최대 50건) |

## 🎮 미니게임 목록

모든 게임은 한 판 1~3분, 스테이지 3개입니다. 스테이지마다 새 규칙이나 장애물이 더해지고, 실수하면 하트나 시간을 잃습니다. 실패하면 그 스테이지부터 다시 하고, 재도전할수록 조금씩 쉬워집니다. 클리어하면 별 1~3개를 받습니다. 게임마다 자세한 기획은 `games/<폴더>/docs/design.md` 에 있습니다.

|---|------|------|----------|
| 02 | 🔑 미로 탈출 | 열쇠 3개를 모아 탈출. 어둠 속 손전등, 쫓아오는 유령 | |
| 03 | 🃏 짝 맞추기 | 외운 카드가 틀릴 때마다 자리를 바꾸고, 도화선 붙은 폭탄 쌍 | |
| 05 | 🧩 숫자 퍼즐 | 목표 이동 수에 맞춰 푸는 퍼즐 3개. 한 수마다 따뜻해/차가워 | |

## 🚀 빠른 시작

### 🏠 홈 트레저헌트 (추천!)

1. `treasure-hunt3/admin.html`을 브라우저에서 엽니다
2. PIN 입력 (기본: `0000`)
3. 테마를 선택하고 시나리오를 불러옵니다
4. 미션을 원하는 대로 커스터마이징합니다
5. 보물 비밀번호를 설정하고 저장합니다
6. 집 안 곳곳에 실물 힌트를 숨깁니다
7. `treasure-hunt3/index.html`을 열어 게임을 시작합니다!

### 🎮 개별 게임 모드

1. `index.html`을 브라우저에서 엽니다
2. 원하는 게임을 고르거나 "오늘의 도전", "아무거나 한 판!"을 누릅니다
3. 난이도와 부모가 정하는 값은 `admin.html` → 게임별 "설정하기"에서 바꿉니다

## 🎯 사용 시나리오 예시

### 생일 파티 보물찾기

1. **준비**: admin에서 "마법 학교" 테마 선택 → 시나리오 로드
2. **커스터마이징**: 물건찾기 미션의 힌트를 집 구조에 맞게 수정
3. **보물 숨기기**: 비밀번호 `생일축하해`로 설정, 선물과 함께 숨기기
4. **시작**: 아이에게 스마트폰을 주고 게임 시작!
5. **진행**: 미니게임 클리어 → 단서 획득 → 물건찾기 → 다음 미션
6. **피날레**: 모든 미션 완료 → 단서 조합 → 보물 발견 → 비밀번호 입력 → 🎉

### 주말 가족 활동

1. **2인 모드** 설정 → 형제/자매가 번갈아 미니게임 플레이
2. 물건찾기 미션은 함께 협력하여 진행
3. 최종 성적으로 실력 비교!

## 📱 모바일에서 사용하기

### 방법 0: NAS (AnglerBox, 권장)

https://pros2.synology.me/minigames/ 를 엽니다. `https://` 라서 카메라와 센서를 모두 쓸 수 있습니다. 게시와 업데이트는 [docs/deploy-anglerbox.md](docs/deploy-anglerbox.md)를 봅니다.

### 방법 1: 로컬 서버

```bash
npm run dev        # 레포 맨 위를 8000번 포트로 연다. 고친 파일은 새로고침하면 바로 보인다
npm run preview    # 게시용 빌드(dist/)를 NAS 와 같은 주소 /minigames/ 로 연다
npm run dev -- --port 9000   # 포트 바꾸기 (쓰는 중이면 저절로 다음 번호)
```

설치할 것은 없습니다(Node 만 있으면 됩니다). 서버가 알려 주는 "같은 Wi-Fi 폰에서" 주소를 스마트폰에서 엽니다.

카메라(바코드 몬스터, 컬러 헌터)는 `https://` 주소나 `localhost` 에서만 열립니다. 집 Wi-Fi 의 `http://` 주소에서는 각각 번호 입력, 사진 올리기로 바뀌어 그대로 할 수 있습니다. 흔들기·방향 센서도 기기에 따라 `https://` 가 필요할 수 있으며, 그때는 버튼이나 손가락 조작으로 바뀝니다. GitHub Pages(방법 2)는 `https://` 라서 카메라와 센서를 모두 쓸 수 있습니다.

### 방법 2: GitHub Pages (무료)

1. GitHub에 코드 업로드
2. Settings → Pages → Source를 main branch로 설정
3. 생성된 URL로 어디서든 접속 가능

### 방법 3: 파일 직접 전송

스마트폰으로 파일 복사 후 브라우저에서 `index.html` 열기 (작전명 스낵 볼트, 우리 집 탐정, 잠수함 간식호는 이 방법으로 열리지 않습니다)

## 💾 데이터 저장

모든 설정과 진행 상태는 브라우저의 `localStorage`에 저장됩니다:
- 서버가 필요 없음
- 같은 브라우저에서는 새로고침해도 유지
- 다른 브라우저나 기기에서는 별도 설정 필요 (보물찾기는 부모 대시보드의 "아이에게 보내기" 링크로 넘깁니다)
- 키 이름은 모두 `minigames:` 로 시작합니다

## 🐛 문제 해결

| 문제 | 해결 방법 |
|------|-----------|
| 게임이 저장되지 않음 | 브라우저 localStorage 활성화 확인, 시크릿 모드 X |
| 모바일 터치 안 됨 | 브라우저 최신 버전 업데이트 |
| 비밀번호 표시 안 됨 | admin에서 저장 확인, 같은 브라우저 사용 확인 |
| 소리가 안 남 | 아이폰은 무음 스위치를 끕니다. 게임 중 ⏸ 버튼에서 소리 켜고 끄기를 확인합니다 |
| 카메라가 안 열림 | 주소가 `http://` 이면 카메라가 막힙니다. 게임이 번호 입력이나 사진 올리기로 바뀌니 그대로 하면 됩니다 |
| 별과 기록을 지우고 싶음 | `admin.html` 맨 아래 "이 기기의 미니게임 별과 최고 기록 지우기"(두 번 누름) |
| PIN을 잊어버림 | 브라우저 개발자도구 → Console → `localStorage.removeItem('minigames:treasureHunt3_admin')` |
| 아이 기기에서 링크가 안 열림 | 링크가 잘리지 않았는지 봅니다. QR 이 안 읽히면 메신저로 링크를 보냅니다 |
